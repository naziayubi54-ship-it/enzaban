# لینگوپلاس: آموزش تعاملی زبان انگلیسی

## تغییرات این نسخه
- تنظیمات در منو (آیکون چرخ‌دنده): تم شب، تلفظ خودکار، سرعت تلفظ، اندازه‌ی متن، هدف روزانه، دیدن دوباره‌ی معرفی؛ دکمه‌ی تم شب/روز جای دکمه‌ی بلندگو آمد
- لوگوی جدید لینگوپلاس (ماسکات کتاب با هدفون): در هدر، منو، صفحه‌ی خانه، اسپلش و آیکون اپ
- صفحه‌ی اسپلش + دو اسلاید معرفی (فقط بار اول): تأکید روی اینکه برنامه برای کسانی است که اصلاً نمی‌توانند با زبان ارتباط بگیرند و همه‌چیز خیلی ساده است
- رفع باگ تمرین‌های درس: ارتفاع ثابت مودال (دیگر بزرگ و کوچک نمی‌شود)، قفل اسکرول صفحه‌ی پشت، شروع دوباره‌ی تمرین از اول در بار بعد
- بازنویسی چرخ انتخاب: کشیدن نرم و پایدار، نشستن روی گزینه، انتخاب با ضربه، بدون اسکرول شدن صفحه هنگام کشیدن
- بخش جدید «پیش‌نیاز» (قدم صفر): ضمیرها، مالکیت با 's، اسم و صفت، ساخت صفت، تر و ترین، و اسکلت جمله
- هدر شناور جدید (منوی سه‌خط، لوگو، نام برنامه، زنگ اعلان با شمارنده)
- منوی کناری که از سمت راست وارد می‌شود و با کشیدن به سمت بیرون بسته می‌شود
- نوبار پایین کپسولی + دکمه گرد «+» برای شروع سریع تمرین
- فونت کل برنامه: وزیر (Vazirmatn) به‌صورت آفلاین داخل برنامه
- صفحه ۱۲ زمان: خط زمان (گذشته ← الان → آینده) + نمودار شکل عمل هر زمان
- بخش «کجاها به کار می‌رود؟» با مثال برای هر ۱۲ زمان
- آیکون‌های مرتبط برای هر زمان (رنگ‌ها همان قبلی)
- حذف یادداشت‌های برنامه‌نویس مثل «از چپ به راست»
- رفع باگ‌ها: انیمیشن‌های تعریف‌نشده، آمار ساختگی کاربر جدید، زنجیره روزانه که هیچ‌وقت آپدیت نمی‌شد، شمارنده امروز که روز بعد صفر نمی‌شد، امتیاز تکراری با تکمیل دوباره درس، تاریخ UTC به‌جای تاریخ محلی، ثبت نشدن زمان‌های یادگرفته، ذخیره نشدن تنظیم صدا، دکمه برگشت اندروید، فونت وابسته به اینترنت

## اجرا در مرورگر
```bash
npm install
npm run dev
```

## ساخت APK (وب‌ویو با Capacitor)

### روش ۱: روی کامپیوتر خودت
پیش‌نیاز: Node.js 20+، JDK 21، Android Studio (Android SDK)
```bash
npm install
npx cap add android      # فقط بار اول
npm run apk              # build + sync + gradle
```
فایل APK اینجاست: `android/app/build/outputs/apk/debug/app-debug.apk`

یا با `npm run apk:open` پروژه را در Android Studio باز کن و از منوی Build > Build APK بساز.

آیکون و اسپلش اندروید از پوشه‌ی `assets/` ساخته می‌شود (بعد از `npx cap add android`):
```bash
npx @capacitor/assets generate --android
```

### روش ۲: بدون نصب هیچ چیز (GitHub Actions)
1. پروژه را در یک ریپوی GitHub آپلود کن.
2. تب Actions → Build Android APK → Run workflow
3. بعد از چند دقیقه، APK را از بخش Artifacts دانلود کن.
